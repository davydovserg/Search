# Search — организации Москвы с Яндекс Карт → Google Таблица

Программа открывает Яндекс Карты в обычном окне браузера, ищет по запросу
(«салоны красоты», «автозапчасти», что угодно) и проходит Москву по округам.
Для каждой организации сохраняет название, телефон, адрес, ссылку на карточку,
сайт и категории, а потом записывает всё в Google Таблицу.

## Установка (один раз)

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

## Запуск

```bash
python search.py "салоны красоты"                 # вся Москва
python search.py "салоны красоты" --okrug ЦАО     # один округ
python search.py "автозапчасти" --segment Север   # одна сторона света
python search.py "салоны красоты" --no-sheet      # только CSV, без таблицы
python search.py "салоны красоты" --only-send     # дослать собранное в таблицу
```

Округа: ЦАО САО СВАО СЗАО ВАО ЮВАО ЮАО ЮЗАО ЗАО ЗелАО НАО ТАО.
Стороны света: Центр, Север (САО, СВАО, СЗАО, ЗелАО), Восток (ВАО, ЮВАО),
Юг (ЮАО, ЮЗАО), Запад (ЗАО, НАО, ТАО). Поменять можно в `geo.py` → `SEGMENTS`.

**Остановить:** Ctrl+C или закрыть окно консоли. Следующий запуск с тем же
запросом продолжит с того же места, и дублей не будет.

**Капча.** Если Яндекс спросит «Вы не робот?», программа пискнет и будет ждать.
Нажмите галочку в окне браузера, и сбор продолжится. Программа капчу не обходит.

Результат сохраняется в `output/<запрос>.csv` (открывается в Excel) и в Google Таблицу.

## Как это работает

1. Округа (их границы в `districts.geojson`, данные OpenStreetMap) покрываются сеткой квадратов.
2. В каждом квадрате открывается поиск, и список листается до конца. Данные берутся из ответов,
   которые сайт сам получает для списка, поэтому телефоны есть сразу, без открытия карточек.
3. Яндекс показывает на один участок карты только ~60–90 мест. Если их столько, квадрат
   делится на 4 помельче, и так до масштаба 17 (~500 м).
4. Каждая организация по координатам относится к своему округу и стороне света.
   Дубли убираются по ID Яндекса.
5. Темп спокойный, как у человека. Работа идёт в отдельном профиле браузера (`data/browser-profile`),
   без вашего аккаунта Яндекса.

## Google Таблица (один раз)

Используется отдельный скрипт, а скрипт внутри самой таблицы не трогается.

1. Откройте https://script.google.com → «Новый проект» и вставьте код из `apps-script/Code.gs`.
2. Шестерёнка «Настройки проекта» → «Свойства скрипта» → добавьте свойство `TOKEN`
   с любым длинным паролем.
3. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»,
   «Запуск от имени: я», «У кого есть доступ: все». Разрешите доступ к таблицам и скопируйте URL.
4. Скопируйте `config.example.json` в `config.json` и впишите туда URL и пароль.
   `config.json` в Git не попадает.

Под каждый запрос создаётся своя вкладка с его названием. Чтобы писать в конкретную вкладку,
укажите её `gid` в `config.json` → `tabs` или флаг `--gid`.
